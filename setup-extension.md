# How to Install on Lemur Browser (Android) 📱

Since Lemur Browser supports desktop Chrome extensions on mobile, you can run this chaotic zoom extension directly on your Android device.

## Prerequisites
Before starting, make sure you have all the project files (`manifest.json`, `popup.html`, `popup.js`, `background.js`, `styles.css`) saved together in a **single folder** inside your Android device's internal storage or downloads folder.

## Step-by-Step Installation

1. **Open Lemur Browser** on your Android device.
2. Tap the **Extensions icon** (the puzzle piece) in the bottom navigation bar or menu.
3. Select **Extension Management** (or go directly to `chrome://extensions/` in the URL bar).
4. Turn on **Developer Mode** using the toggle switch (usually found at the top or in the settings menu of that page).
5. Tap the **Load Unpacked** button (sometimes labeled as `+` or `Load local extension`).
6. Your Android file manager will pop up. Navigate to your project folder and select the **`manifest.json`** file (or select the entire folder depending on your file manager).
7. The extension **I CANT FIND THE TEXT!** is now installed!

## How to Trigger the Chaos
1. Navigate to any website (e.g., Wikipedia).
2. Tap the **Extensions icon** (puzzle piece) in your browser toolbar.
3. Tap **I CANT FIND THE TEXT!** to open the popup.
4. Hit **ACTIVATE CHAOS**. The page will reload, and you can enjoy navigating a 1000% zoomed desktop site on a tiny mobile screen!
